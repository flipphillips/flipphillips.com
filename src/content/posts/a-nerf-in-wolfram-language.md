I wanted to train a NeRF (Neural Radiance Field) from scratch in Wolfram Language. I was inspired by the [original NeRF paper](https://arxiv.org/abs/2003.08934) and wanted to see if I could implement it using the tools available in Wolfram Language.

So - here you go! This links to the Wolfram Community post. 

[Training a neural radiance field (NeRF) from scratch in Wolfram Language: the classic Lego bulldozer](https://community.wolfram.com/t/training-a-neural-radiance-field-nerf-from-scratch-in-wolfram-language-the-classic-lego-bulldozer/28600)

If you want the GitHub repo, you can find it here: [Wolfram Language NeRF](https://github.com/ritmps/WLNeRFLite)
