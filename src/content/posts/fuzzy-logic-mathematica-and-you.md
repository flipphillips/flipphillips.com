I was working on a project in Gießen last week and needed some code I wrote back in the late 1980’s / early 1990’s.

Sadly, this is no replacement for the super cool `FuzzyLogic` [Mathematica package](http://library.wolfram.com/infocenter/TechNotes/4626/) (RIP).

It is simply the ten fuzzy boolean operators + a few things here and there that add to the fun. It implements the traditional ‘Zadeh’ operators, along with Yager and HyperbolicParaboloid variants, selectable with `Method`.

Let’s hear it for being a complete packrat. Added to the [Software, Data & Geometry page](https://academics.skidmore.edu/blogs/flip/?page_id=669) is a _very_ old fuzzy logic package. You can make a direct hop over to [GitHub here](https://www.github.com/flipphillips/Fuzzy).
